CSV format guidetime_seconds,voltage_relative

Two numeric columns with evenly spaced timestamps in seconds. Classification uses 1,200 measurements at 6,000 Hz, covering 0.2 seconds. Scale voltage relative to a nominal peak of 1.0. Other recordings with up to 50,000 measurements can be previewed. Maximum file size is 5 MB.
